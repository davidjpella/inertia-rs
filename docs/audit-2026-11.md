# Protocol Audit: inertia_rs 0.4.0 vs Inertia 3.11.0

Audit date: 2026-11-20. Target: see [`compatibility-target.md`](compatibility-target.md).
Audited revision: `ff023d1` (Release 0.4.0).

This audit records the state of the code **before** the 3.11 compatibility work.
It was produced by reading `src/lib.rs`, `src/axum.rs`, `src/rocket.rs`, the
test suites, and comparing them with the protocol specification and the
reference adapter (`inertia-laravel` v3.7.0: `Middleware.php`,
`PropsResolver.php`, `Response.php`, prop classes). The post-implementation
matrix lives in [`protocol-support.md`](protocol-support.md).

Status vocabulary: **complete**, **partial**, **missing**, **client-only**,
**app** (application responsibility), **experimental**.

## Backlog (implementation order)

1. **Core resolver rewrite** (#10–#22, #26): prop tree with path-based
   filtering, typed props (always/optional/defer/once/merge/scroll/live/rescue),
   sync and async providers resolved concurrently, reference-compatible
   metadata. Shared props flow through the same resolver.
2. **Page object fixes** (#4, #17, #24–#26): `version` default, `flash`,
   session-carried flags, `preserveBigIntegers`.
3. **Axum middleware** (#3, #5–#9, #29): one `InertiaLayer` covering `Vary`,
   version checks, 303 conversion, fragment redirects, reflash.
4. **Session abstraction + Axum session integration** (#23–#25).
5. **Rocket parity** for the protocol fixes and async rendering.
6. **SSR bridge** (#28).
7. **Live props** (#27) with an SSE transport example.
8. **Experimental Layers** (#34).
9. Examples, browser tests (React full, Vue/Svelte smoke), CI, docs.
